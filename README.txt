IATA Lernkarten – iPhone Offline-Version

Wichtig:
Eine PWA kann auf dem iPhone nicht direkt aus der Dateien-App als App installiert werden.
Sie muss EINMAL über Safari von einer HTTPS-Webadresse geöffnet werden.

Danach:
1. Die Seite in Safari öffnen.
2. Teilen > Zum Home-Bildschirm.
3. Die App einmal starten, solange Internet verfügbar ist.
4. Danach funktioniert sie offline.

Alle 168 Lernkarten und die Logik sind lokal in der App enthalten.
Es werden keine externen Bibliotheken oder Internetdienste benötigt.
